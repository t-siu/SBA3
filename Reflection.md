The main challenge of this project was identifying and applying the exact syntax and commands needed to configure and build each component from scratch. To overcome this, I broke 
the development process down into smaller, manageable steps and dedicated time outside of class to study documentation, test command behavior, and reinforce my understanding.
Given more time, I would spend extra hours upfront practicing core commands and establishing a structured research workflow.
